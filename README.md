# Breakapart

_Breakapart_ is a [multidirectional shooter](https://en.wikipedia.org/wiki/Shoot_%27em_up#Multidirectional_shooters) game for RetroArch. Special thanks to [Berbasoft](https://berbasoft.com/) for the concept and tutorial.

The game is programmed in Lua using object-oriented programming concepts as described by [_Programming in Lua (first edition)_, Chapter 16](https://www.lua.org/pil/16.html).
